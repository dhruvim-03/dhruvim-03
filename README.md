## 🚀 Featured Engineering Projects

### 📡 [RiskRadar — AI-Powered Fraud Detection & Monitoring](https://github.com/dhruvim-03/RiskRadar)
*Real-time transaction fraud scoring with SHAP explainability and data-drift monitoring.*

- Built a **real-time scoring pipeline**: a Spring Boot backend orchestrates an internal **FastAPI + XGBoost** service and returns a fraud probability with a **LOW / MEDIUM / HIGH** risk tier.
- Engineered **leakage-safe velocity features** from prior transactions only, trained on highly imbalanced data and evaluated on **PR-AUC**.
- Added **SHAP explanations** to every prediction so analysts can see exactly why a transaction was flagged.
- Implemented a scheduled **PSI-based drift monitoring** job that flags feature drift above the 0.2 threshold.
- Secured the platform with **JWT auth and role-based access** (Analyst / Admin), plus an admin-triggered **model retraining** workflow with version history.
- Built a responsive **React + TypeScript dashboard** (Tailwind, shadcn/ui, Recharts) and containerized the full stack with **Docker Compose**.

**Tech Stack:** `Spring Boot` • `FastAPI` • `XGBoost` • `SHAP` • `React` • `TypeScript` • `PostgreSQL` • `Docker`
